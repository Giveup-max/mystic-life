# 规则来源与扩展说明

本 skill 的“命理特征 → 生活选择”映射由多个公开流传的流派规则汇集而成，**没有唯一权威标准**。以下说明来源与简化程度，便于按需修改或扩展。

## 推算引擎

- `lunar-python`（6tail，MIT 许可）：负责八字四柱、天干地支、五行、纳音、生肖、每日宜忌、吉神方位、星宿、黄黑道等，已 vendor 进 `scripts/vendor/`，开箱即用。
- 所有规则集中在 `scripts/calculate.py` 顶部的常量表中，修改即生效。

## 喜用神：三视角

- **扶抑**：按日主五行出现次数判身强弱（≥3 视为身强）。身强喜克（官杀）、泄（食伤）、耗（财）；身弱喜生（印）、扶（比劫）。这是“补弱/扶抑”法。
- **调候**：按月支定季节（春木火、夏水金、秋水火、冬火木）。冬生需火暖、木疏。
- **日主特性**：按日主天干的传统喜忌（如戊土喜甲木疏、丙火暖、癸水润）。
- 三种视角可能互相矛盾（如身强忌火、调候又需火），这正是命理流派不一致的体现，应如实呈现、让用户体感裁决。

## 个人档案权重

- 每条观察含 `kind`（偏好/体感）、`times`（次数）、`verdict`（利/弊/中性）。
- 体感权重是偏好的 2 倍；次数按 `1 + 0.2*(min(times,5)-1)` 微调；“利”加分、“弊”减分，汇总到五行得分。
- 得分 > 0 的五行进入“有利”，< 0 进入“不利”；`life` 模式以有利第一项为主用色，并提示避开不利项。
- 档案按五行粒度汇总，同一五行内若有分歧（如红色弊、橙色利），需回到具体条目判断。

## 各维度映射

- 幸运色：五行 → 颜色（金白金银/木绿青/水黑蓝/火红紫橙/土黄棕）。
- 幸运食物：五行 → 五味五色食物，融合中医五行食疗与“五色入五脏”说法。
- 水晶：五行 → 对应水晶；招财另加黄水晶、钛晶、金发晶、绿幽灵。
- 方位：五行 → 方位（木东/火南/土中/金西/水北）；命卦用八宅法（东四命/西四命）。
- 手机品牌：按品牌主色调自定义五行归类（Apple 金、华为/一加 火、小米/realme/iQOO 土、OPPO 木、三星/vivo/荣耀/魅族/索尼 水）。**自定义规则，非公认命理**。
- 手机号数字能量：公开流传的“数字能量八星”（天医/生气/延年/伏位/绝命/五鬼/六煞/祸害），两位组合判吉凶，0、5 跳过。

## 当日决策与择日

- 数据来自老黄历：宜忌、吉神、喜/财/福/贵神方位、值星（建除十二神）、天神黄黑道、二十八星宿吉凶。
- 择日可结合用户生肖避开“冲其生肖”的日子，并优先宜“纳财/交易/立券/开市/出行”的日子。

## 大运与流年

- 大运：由 `lunar-python` 的 `getYun(gender)` 排定（分男女顺逆），输出各步大运干支与五行。
- 流年：按指定年份干支，判断其五行对日主的关系（比劫/印/食伤/官杀/财）、是否冲用户生肖，并对照喜忌给倾向。

## 修改规则

编辑 `scripts/calculate.py` 顶部常量表：

- `WX_COLOR` / `WX_FOOD` / `WX_CRYSTAL` / `WX_DIR`：五行 → 对应条目。
- `BRAND_WX`：品牌 → 五行，可增删品牌。
- `EIGHT_STARS`：数字两位组合 → (星名, 吉凶, 含义)。
- `ITEM_WX_HINTS`：`record` 时从颜色/物品文字自动推断五行用的关键词。

修改后无需重新安装，下次运行即生效。
